# 품질 반려의 국소 수정 검증

모든 요청·원문·후보는 고정 합성 과제다. runs.json에는 일반 실행 4건, 환경 변경 차단 1건, 통제 결함을 넣은 복구 실행 2건을 모두 남겼다. 차단 본문은 전달 결과에 없어 null이다. 통제 결함은 원문에 없는 마지막 문장 하나를 초안에 넣은 것이고, 계획·반려·수정·재검토는 실제 모델 호출이다.

protocol.json은 최초 실행 전 과제·평가 기준이다. 후속 실행 이유는 environment-failure.json과 runs.json에 남겼다. local-blind-candidates.json은 이전 컴파일 결과 4개와 이번 일반 결과 4개다. 평가자는 후보 파일만 읽고 local-blind-scores.json을 작성했다. 조건표는 local-blind-key.json이다. 양쪽 기준 4/4 통과, 자연스러움 평균 4.0→3.75이므로 품질 동등성·향상을 입증했다고 주장하지 않는다.

replay-parity.json은 동일한 실제 응답을 기존·최종 실행기에 넣은 정상 경로 비교다. 모델 호출 없이 실제 검사 10회를 수행해 4개 사례의 본문·검사 횟수·작성 지침·작성 요청이 같음을 확인했다. 검토 지침의 국소 지적 형식 추가는 차이로 남겼다. 점수 변동 원인이나 보편적 동등성을 증명하지 않는다.

summary.json 전체 사용량에는 환경 차단과 두 통제 복구 실행이 포함된다. 예전 57.99%를 이번 절감률로 재사용하지 않는다. 공개 자료에는 소스 구현·전체 지침·운영자 경로·자격 증명을 포함하지 않는다.
