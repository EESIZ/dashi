# 품질 반려의 국소 수정 검증

이 디렉터리의 현재 파일은 고정 합성 과제의 본문 없는 검증 기록이다. 작성 요청·원문·초안·완성 본문·제공자 응답과 자유 서술 평가 사유는 저장소에서 철회했다. 원본 증거는 Git 밖의 접근 제한된 비공개 보관소에 보존한다. 공개·비공개 저장소와 배포물 모두에 작성 본문을 다시 추가하지 않는다.

`runs.json`에는 일반 실행 4건, 환경 변경 차단 1건, 통제 결함을 넣은 복구 실행 2건의 상태·사용량·해시·검사 및 단계 기록을 남겼다. 본문 필드는 성공·차단 여부와 관계없이 제거했다. 통제 결함은 원문에 없는 문장 하나를 초안에 넣는 시험이었고, 계획·반려·수정·재검토는 실제 모델 호출이었다. 본문 철회로 실패 기록이나 비용을 제외하지 않았다.

`protocol.json`은 최초 실행 전의 과제 식별자·평가 기준·시험 방법이다. 후속 실행 이유는 `environment-failure.json`과 `runs.json`에 남겼다. 이전 컴파일 결과 4개와 이번 일반 결과 4개를 조건을 가리고 평가한 사실은 유지하되, 후보 파일은 제거했다. `local-blind-scores.json`에는 기준별 판정과 점수만, `local-blind-key.json`에는 조건 매핑만 남겼다. 양쪽 기준 4/4 통과, 자연스러움 평균 4.0→3.75이므로 품질 동등성·향상을 입증했다고 주장하지 않는다.

`replay-parity.json`은 동일한 실제 응답을 기존·최종 실행기에 넣었던 정상 경로 비교의 해시·횟수·일치 판정이다. 응답 본문은 포함하지 않는다. 모델 호출 없이 실제 검사 10회를 수행해 4개 사례의 본문·검사 횟수·작성 지침·작성 요청이 같음을 확인했다. 검토 지침의 국소 지적 형식 추가는 차이로 남겼다. 점수 변동 원인이나 보편적 동등성을 증명하지 않는다.

`summary.json` 전체 사용량에는 환경 차단과 두 통제 복구 실행이 포함된다. 예전 57.99%를 이번 절감률로 재사용하지 않는다. 원문 철회는 역사적 결과를 바꾸거나 현재 기록만으로 원문 재평가가 가능하다는 뜻이 아니다.
