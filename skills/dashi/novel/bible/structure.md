# Structure

```
DIR/
  bible.json      title, time_unit, now_ep, now_t
  overview.json   logline, intent, genre, platform, tone
  synopsis.json   whole story, arcs
  style.json      pov, tense, voice, devices, conventions
  entities/<id>.json   character | place | faction | system | term | item
  events/<id>.json     things that happen in story time
  episodes/NNN.json    one per published chapter
  threads.json         foreshadowing / open questions
  changes.jsonl        append-only log written by apply
  index.json           generated by index/apply
```

Two time axes:
- `t` story time, a number in `time_unit` (e.g. days). Sortable.
- `ep` chapter number = publication order. Flashbacks have small `t`, large `ep`.

Facts carry an interval `[from_t, to_t)`; `to_t: null` = still true. Changing a fact closes the old one and adds a new one, so history stays.

Retired settings are removed from files and logged once in `changes.jsonl`.

See: schema, changes.
