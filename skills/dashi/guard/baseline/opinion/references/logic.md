# 전개 방식 (논설)

글을 쓰기 전에 요청이 묻는 것에 맞는 흐름을 하나 고른다. 전개 방식은 글의 뼈대이고, 어떤 문장과 호흡으로 채울지는 스타일 좌표가 따로 정한다. 두 층을 섞지 않는다.

키는 세 묶음이다. E는 사설·칼럼처럼 일어난 일에 대해 쓰는 글, A는 논술·주장문·토론문처럼 논제에 답하는 글, O는 어느 묶음에나 얹는 조직 방식이다.

## E. 사건 논평 (사설·칼럼)

사람 사설 69편에 문장 기능 꼬리표를 달아 문단 흐름을 세어 보니, 첫 문단은 사실로 여는 글이 30%, 판단으로 여는 글이 39%였고, 마지막 문단은 87%가 촉구로 닫혔다. 아래 표의 전개는 그 흐름에서 뽑은 것이다.

| 키 | 상황과 방식 | 전개 |
|---|---|---|
| E01 | 사건 논평: 방금 일어난 일에 대해 신문의 입장을 세울 때 (가장 흔한 틀) | 사실 제시(당사자 발언 전문 포함) → 그 일의 뜻·배경 풀이 → 판단 → 당사자에게 촉구 |
| E02 | 판단 선행: 독자가 이미 사건을 알고 있어 평가부터 듣고 싶어 할 때 | 사실 한 줄과 판단을 첫 문단에 → 판단을 받치는 사실 → 판단 보강 → 촉구 |
| E03 | 양비·양시: 두 당사자가 맞서고 신문이 어느 한쪽에 서지 않을 때 | 한쪽 사실과 판단 → 다른 쪽 사실과 판단 → 두 쪽에 공통으로 요구 |
| E04 | 경고·전망: 아직 일어나지 않은 결과를 막으려 할 때 | 현재 사실 → 흘러갈 방향 풀이 → "이대로 가면"의 조건 문장 → 지금 할 일 촉구 |
| E05 | 지지·환영: 결정이나 성과를 평가하되 남은 과제를 붙일 때 | 사실 → 긍정 판단 → 아직 안 된 것 → 다음 단계 촉구 |
| E06 | 책임 추궁: 당사자의 해명이 있고 그것을 받아들이지 않을 때 | 사실 → 당사자 해명을 전문으로 옮김 → 해명과 사실의 어긋남 → 책임 요구 |
| E07 | 사례에서 일반화: 한 사람·한 장면에서 시작해 사회 문제로 넓힐 때 (칼럼) | 구체 사례 → 사례가 보여 주는 것 → 같은 구조의 다른 사례 → 교훈 또는 제언 |
| E08 | 비교·대조: 다른 나라·과거·경쟁 기관과 견줘 차이를 드러낼 때 | 비교 대상 제시 → 우리 쪽 사실 → 차이의 뜻 → 차이를 좁힐 요구 |

E 묶음의 끝은 거의 촉구다. 판단으로 닫는 글은 13%였고, 그때는 마지막 판단이 한 문장짜리 짧은 문단이었다.

## A. 논제 답변 (논술·주장문·토론문)

대입 논술 지도에서 굳어진 유형을 따른다. 논제가 "찬성이냐 반대냐"면 A01, "어떻게 해결할까"면 A02, "이 명제가 옳은가"면 A03, "두 관점을 견줘라"면 A04다.

| 키 | 상황과 방식 | 전개 |
|---|---|---|
| A01 | 찬반(논쟁): 논제가 입장을 요구할 때 | 입장 선언 → 근거 둘 또는 셋(각각 사실로 받침) → 가장 센 반론 제시 → 재반박 → 입장 재확인 |
| A02 | 문제 해결: 논제가 대안을 요구할 때 | 문제 특정 → 원인 분석 → 대안 → 대안의 조건과 한계 → 결론 (결론이 끝에 오는 미괄이 보통) |
| A03 | 명제 논증: 주어진 명제가 옳은지 보일 때 | 명제 확인 → 핵심 개념 규정 → 근거(일반 원리에서 내려오거나 사례에서 올라감) → 결론 |
| A04 | 관점 비교: 둘 이상의 입장을 견주라고 할 때 | 비교 기준 설정 → 관점 하나 → 관점 둘 → 기준에 비춘 차이 → 자기 입장 |
| A05 | 현상 해석: 자료나 현상의 원인과 함의를 묻을 때 | 현상 서술 → 원인 또는 구조 → 함의 → 조건부 전망 |
| A06 | 통념 뒤집기: 널리 믿는 생각에 맞설 때 | 통념 제시 → 통념이 서는 조건 → 그 조건이 깨지는 사례 → 종합된 새 명제 |
| A07 | 토론 입론: 토론에서 처음 말할 때 | 논제의 핵심 용어 정의 → 판단 기준 → 쟁점 둘 또는 셋 → 쟁점마다 근거 → 결론 |
| A08 | 토론 반박: 상대 주장에 답할 때 | 상대 주장 요약 → 전제·근거·추론 중 어디가 약한지 특정 → 상대 전제를 가정해도 결론이 안 나옴을 보임 → 자기 쪽 근거 재강조 |

## O. 조직 방식

| 키 | 상황과 방식 | 전개 |
|---|---|---|
| O01 | 두괄: 결론을 먼저 내고 근거로 받칠 때 (사설 절반은 글의 17% 안에서 첫 판단이 나온다) | 결론 → 근거 → 결론 재확인 또는 촉구 |
| O02 | 미괄: 근거를 쌓아 결론에 이르게 할 때 (문제 해결형 논술의 보통) | 사실·근거 → 결론 |
| O03 | 양괄: 긴 글에서 결론을 앞뒤로 둘 때 | 결론 → 근거 → 같은 결론을 다른 말로 |
| O04 | 반론 선제: 독자가 먼저 떠올릴 반대가 분명할 때 | 반론 먼저 → 재반박 → 자기 근거 |
| O05 | 반론 후치: 자기 근거가 충분히 선 뒤 반론을 다룰 때 | 자기 근거 → 반론 → 재반박 |
| O06 | 조건 마무리: 촉구 대신 "~면 ~된다"로 닫을 때 (사설의 조건 문장은 글의 뒤쪽 3분의 1에 몰린다) | 근거 → 조건 문장 → 짧은 판단 |

## 고르는 법

- 요청이 사건을 주면 E, 논제를 주면 A다. 둘 다면 E로 쓰고 A의 반론·재반박 칸을 빌린다.
- 전개 방식 하나에 조직 방식 하나를 얹는다. E02에 O01이 겹치듯 이미 포함된 조직은 따로 적지 않는다.
- 고른 키와 문단 수를 사용자에게 보인다. 키마다 문단 하나가 기본이고, 근거가 여럿이면 근거 칸만 문단을 늘린다.
- 근거 칸의 사실·수치·인용은 요청이나 자료에 있는 것만 쓴다. 없는 것은 "[확인 필요]"로 표시하고 지어내지 않는다.

## 자료 근거

- 사설 흐름 집계: 2020~2022 한겨레·동아·중앙 사설 69편(문장 1,435개)의 문장 기능 꼬리표(F 사실 459, J 판단 356, R 전문 204, I 해석 182, D 당위 174, C 조건 32, Q 인용 28). 첫 문단 종류 J 27·F 21·I 13·D 7, 마지막 문단 종류 D 60·J 9.
- 논술 유형: 대입 논술 지도 자료의 논쟁형·논증형·설명형·문제해결형 구분과 문제해결형의 미괄 관행.
- 1955~2019 사설은 자료가 없어 집계에 없다. 시대별 흐름 차이는 자료를 넣은 뒤 다시 센다.
