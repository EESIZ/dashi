# 윤문

도구는 MCP 서버 `yunmun`에 있다(설치는 install.sh). 규칙 본문과 기준 분포는 서버 안에 들어 있으므로 도구가 돌려주는 설명을 그대로 따른다.

## 순서

0. **입장** — 쓰기 전에 관계(당사자/우호/비판/심판)·독자·의도 한 동사·안 쓸 말 둘을 정한다. 요청에 없으면 장르 화자 안에서 고르고 사용자에게 보인다. 사람이 쓴 원문을 다듬을 때는 원문의 어미에서 뽑는다.
1. **장르** — `classify(text)` 후보를 요청과 맞춰 정한다.
2. **뼈대** — `skeleton(genre)`가 주는 문장 기능 뼈대와 `rules`를 그대로 따른다.
3. **채우기** — 첫 통과는 사실만 볼 순서대로, 둘째 통과에서 뼈대가 정한 칸만 판단·당위로 채운다. 앞에 없는 근거로 판단하지 않는다.
4. **문장 게이트** — `sentence_gate(text, genre)`. FAIL이면 `regen_prompt(text, genre)`가 주는 프롬프트대로 **실패 문장만** 고쳐 다시 넣는다. PASS까지 반복하되 3회를 넘기면 남은 위반을 사용자에게 보고한다. 사실을 더하지 않는다.
5. **검사** — `check(text, genre)`로 표면 지표를 장르 분포와 대조한다. 경고는 단어가 아니라 동작을 가리킨다.
6. **기록** — 사용자가 고쳐 준 표현은 `correction(before, after, reason)`에 저장하고, 쓰기 전에 `correction(query=…)`로 찾아본다.

## 한계

- 기준 분포는 사설 장르 사람 글에서 계산한 것이다. 다른 장르는 가장 가까운 것으로 쓰고 사용자에게 말한다.
- 게이트는 문장 안과 호흡을 잡는다. 입장 자체는 글 밖의 정보라 어떤 도구도 대신 채우지 못한다.
